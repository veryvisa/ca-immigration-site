知识卡

不看正文也能拿到这一页的核心内容：先看导读，再看图。点图放大，左右翻页。

先看 CEC 硬条件与官方依据。本指南是操作顺序，不代替 IRCC 的完整要求或个人清单。

S0 判断

确认经验、语言与定居意向是否满足当前官方要求。

  • 按 NOC 2021 核对工作职责与 TEER。
  • 按官方规则计算近 3 年的合资格加拿大工作小时；全职、兼职、自雇与在校工作不能混为一谈。
  • 检查四项语言成绩与测试有效期。

材料：语言考试 · 工作证明信

官方核对：Canadian Experience Class ↗ · Express Entry: Language test results ↗

S1 准备

让每项填入档案的信息都有可回查的文件。

  • 备妥已认可的英语或法语考试成绩。
  • 整理雇主证明与辅助记录，核对职位职责、工作时间及授权状态。
  • 核对 IRCC 当前的文件清单；特殊情形按个人清单补件。

材料：语言考试 · 工作证明信

官方核对：Canadian Experience Class ↗ · Express Entry: Language test results ↗

S2 入池

以真实、可证明的信息进入候选池。

  • 先使用 IRCC 的资格工具核对可否进入 EE。
  • 按官方账号流程建立档案并核查每项资料。
  • 记录档案到期日和材料有效期。

官方核对：Express Entry: Who can apply ↗

S3 邀请

收到 ITA 后按账号中的指示推进。

  • 区分 CEC、PNP、类别抽签等不同轮次，不用别的轮次最低分预测自己的结果。
  • 以 IRCC 账号显示的邀请及期限为准。

官方核对：Express Entry: Rounds of invitations ↗

S4 递交

逐项核对当前要求后再递交。

  • 按 IRCC 账号生成的个人文件清单准备证明。
  • 核查工作经历、旅行史与家庭信息前后一致。
  • 费用与证明要求在递交当天回官方页面核对。

材料：中国无犯罪记录证明 · 工作证明信

官方核对：Canadian Experience Class ↗

S5–S8 审理与登陆

按账号通知完成生物信息、体检、补料及最终确认。

  • 保存提交回执和官方通知。
  • 工签临近到期时先查看现行合法身份规则，不把 PR 申请视作自动续签。
  • 以 IRCC 最终决定与落地文件为准。

官方核对：Canadian Experience Class ↗
