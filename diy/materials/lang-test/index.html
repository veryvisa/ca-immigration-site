语言考试

官方确认核对 2026-09-29下次复核 2026-12-28

这是什么、什么时候要

语言成绩单（language test results）是证明你英语或法语水平的官方考试成绩。走 Express Entry（快速通道）时必须有，填档案和递交永久居民申请时都要用。

要点（数字照官方原文）

要点当前已核对的要点原文
认可的考试IRCC 认可英语考试 CELPIP、IELTS、PTE Core，法语考试 TEF Canada、TCF Canada，共五种。IRCC ↗
必须考“通用类”CELPIP 要考 CELPIP-General；IELTS 要考 General Training（通用培训类，不是学术类）；PTE 要考 PTE Core。IELTS One Skill Retake（单项重考）不被接受。IRCC ↗
有效期成绩在你完成 Express Entry 档案时、以及递交永久居民申请时，都必须不到 2 年。过期成绩会导致申请被拒。IRCC ↗
最低要求加拿大经验类（CEC）：TEER 0 或 1 的工作要 CLB 7，TEER 2 或 3 的要 CLB 5，四项能力都要达标。联邦技术移民（FSW）：第一官方语言四项都要 CLB 7。IRCC ↗
CLB 7 对应英语分数（听说读写）IELTS 口语6.0、听力6.0、阅读6.0、写作6.0；CELPIP 四项都是 7；PTE Core 口语68–75、听力60–70、阅读60–68、写作69–78。（表中顺序：Speaking、Listening、Reading、Writing）IRCC ↗
CLB 5 对应英语分数（听说读写）IELTS 口语5.0、听力5.0、阅读4.0、写作5.0；CELPIP 四项都是 5；PTE Core 口语51–58、听力39–49、阅读42–50、写作51–59。IRCC ↗
CLB 7 / 5 对应法语分数（NCLC）TEF Canada 的 NCLC 7：口语310–348、听力249–279、阅读207–232、写作310–348；NCLC 5：口语226–270、听力181–216、阅读151–180、写作226–270。TEF 要填“Équivalence ancien score”那一列，不要填“Score / 699”。IRCC ↗
TCF Canada 对应分数TCF Canada 的 NCLC 7：口语10–11、听力458–502、阅读453–498、写作10–11；NCLC 5：口语6、听力369–397、阅读375–405、写作6。IRCC ↗

怎么办

  1. 先确定你要走的项目（CEC、FSW 等）以及需要的 CLB 等级，再选考试。
  2. 到 IRCC 认可的考试机构报名并付费，注意选“通用类”版本。
  3. 拿到成绩后，把成绩输入你的 Express Entry 档案（系统要求时还要填成绩单编号和 PIN）。
  4. 算好日期：递交申请时成绩必须不到 2 年。

易错点

  • TEF Canada 成绩单上有两列分数，只能填“Équivalence ancien score”那一列；填错可能被拒。原文 ↗
  • 成绩在你还没被邀请时就可能过期；官方建议重考、或在过期前申请。原文 ↗

官方没有明说、或因人而异的点：

  • 上表分数取自 IRCC 语言考试页的对照表（CLB 7 用 FSW 表、CLB 5 用 CEC/FST 表）。
  • 考试报名费与考位由考试机构公布，IRCC 页面不列。

哪些项目要用到

  • 加拿大经验类
  • 联邦技术移民
  • 联邦技工类
  • 大西洋移民计划
  • 农村社区移民试点
  • 法语社区移民试点
  • 创业签证
  • 自雇移民
  • 住家照护者移民试点
  • 农业食品试点
  • 毕业工签
  • 入籍申请（授予）
